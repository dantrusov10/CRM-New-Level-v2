### КП — целевая логика

1. **Шаблон** — блоки (шапка, таблица, итоги, условия) drag-and-drop или список секций.
2. **Прайс** — загрузка Excel/CSV → позиции в `price_list_items`.
3. **Сборка** — выбор позиций из прайса + скидки → мгновенный preview → PDF.
4. **Версии** — сохранение `kp_instances` по сделке.
